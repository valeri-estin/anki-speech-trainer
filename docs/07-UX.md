# 07 — UI / Zustände

## Ziel

Kleines, ästhetisch zurückhaltendes Modul direkt auf der Vorderseite der betroffenen Anki-Karten. Anki-Kartentext und globale Antwortbuttons werden nicht ersetzt. Dark Mode und Tastaturbedienung unterstützen.

## Zustände / Copy

| Status | Anzeige | Aktionen |
| --- | --- | --- |
| `idle` | `Sprechen üben` | `Sprechen` |
| `worker_starting` | `Spracherkennung wird geladen …` | `Abbrechen` |
| `ready` | `Bereit` | `Sprechen` |
| `recording` | `Ich höre zu …` plus deutliche Mikrofonsymbolik | `Stoppen`, `Abbrechen` |
| `transcribing` | `Sprache wird erkannt …` | `Abbrechen` |
| `match` | `Erkannt: la casa` / `Text stimmt überein` | `Erneut sprechen` |
| `mismatch` | `Erkannt: la cosa` / `Text weicht ab` | `Erneut sprechen` |
| `uncertain` | `Nicht sicher erkannt. Bitte erneut versuchen.` | `Erneut sprechen` |
| `error` | `Mikrofon nicht verfügbar` oder technischer Fehler | `Erneut versuchen` |

## Interaktion

- Nicht automatisch auf `Sprechen` schalten, wenn Karte geöffnet wird.
- Nach Sprachpause Aufnahme automatisch stoppen; alternativ manuell stoppen. Bei längerer Stille vor dem ersten Wort nicht endlos warten (konfigurierbarer Timeout).
- Keine blinkende Animation, die bereits beim Anzeigen der Karte wie aktives Mikrofon aussieht.
- Auf der Frageseite **niemals die Musterantwort vorzeitig enthüllen**: Vor `Antwort anzeigen` bei `mismatch` nur `Erkannt` + `Text weicht ab`, nicht `Erwartet`. Nach dem Aufdecken darf die Lösung wie gewohnt sichtbar sein.
- Bei `match` die Antwort ebenfalls nicht als Text anzeigen, bevor der Nutzer selbst aufgedeckt hat, wenn dies ein Lernziel betrifft; Transkript ist naturgemäß sichtbar und entspricht seiner eigenen Äußerung.
- Keyboard-Fokus/Space/Enter der normalen Anki-Bedienung nicht abfangen; optional konfigurierbarer anderer Shortcut erst später.
- Ergebnis nicht über Kartenwechsel mitnehmen. Mehrere Klicks auf Start nicht mehrfach aufnehmen.
- Fehlertexte kurz, sachlich; Debugdetails in stderr und bei Bedarf Log.

## Sichtbarkeit / Design

Eigene CSS-Klassen (`ast-*`), große Mikrofontaste, Status in Text und nicht nur Farbe. Minimaler Kontrast entsprechend WCAG AA anstreben. Keine fremden Online-Fonts/CDN. Keine generellen Duolingo-Markenassets.
