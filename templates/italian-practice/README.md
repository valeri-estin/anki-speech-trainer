# Italian Practice source assets

This directory contains the optional importable `Italian Practice.apkg` and a semicolon-separated
CSV source example. The package has four native card templates: Recognition, Speaking, Writing,
and Listening. It contains no worker, model, audio recording, or imported scheduling history.

Read `docs/15-ITALIAN-PRACTICE.md` before importing. In particular, assign deck overrides manually
after import and configure the speech add-on only for the exact `Speaking` card template.
